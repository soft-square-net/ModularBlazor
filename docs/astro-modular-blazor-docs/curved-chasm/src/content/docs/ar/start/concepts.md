## بنية الجزر (Islands)

صفحة Astro هي HTML أولا. وكل مكون تفاعلي فيها **جزيرة**: يعرض HTML على الخادم أو أثناء البناء، ثم تحمل
شيفرة JavaScript الخاصة به وتشغل (الإحياء أو hydration) بشكل منفصل، لهذا المكون وحده. ويبقى باقي الصفحة
ثابتا. فلا تعطل أداة بطيئة المقال المحيط بها أبدا.

أما Blazor WebAssembly في هذا المشروع فيعمل بالعكس: الواجهة كلها تطبيق واحد يعرض في المتصفح بعد أن تبدأ بيئة
تشغيل .NET. وتتيح الجزر استخدام Blazor في **جزء** من الصفحة بدلا من الصفحة كلها.

## موجهات العميل

يحدد Astro موعد تشغيل الجزيرة بموجه `client:*`. ولدى Astro تكاملات مع React وVue وSvelte وSolid وPreact، لكن
ليس مع Blazor، لذلك لا تستطيع جزيرة Blazor استخدام هذه الموجهات مباشرة. ويحاكي مكون
[`<BlazorIsland>`](/ar/guides/blazor-islands/) في هذه الأدلة سلوكها عبر الخاصية `load`:

| موجه Astro | يبدأ عندما | `<BlazorIsland load=…>` |
| --- | --- | --- |
| `client:load` | تحمل الصفحة | `load="eager"` |
| `client:idle` | يصبح المتصفح خاملا (`requestIdleCallback`) | `load="idle"` |
| `client:visible` | تظهر الجزيرة على الشاشة (`IntersectionObserver`) | `load="visible"` (الافتراضي) |
| `client:media="(…)"` | يتحقق استعلام وسائط | `load="media"` مع `media="(…)"` |
| `client:only` | تحميل الصفحة، دون HTML معروض مسبقا | بلا محتوى في الفتحة |

## جزر الخادم

يعرض `server:defer` مكونا على الخادم **مع كل طلب** ويبثه بعد الصفحة الثابتة. وعميل Blazor WebAssembly المستقل
لا يعرض شيئا على الخادم، فلا مقابل له في Blazor. إن احتجت محتوى خاصا بكل مستخدم في صفحة عامة، فاستخدم جزيرة
خادم في Astro (مع محول SSR) تستدعي الواجهة البرمجية، أو اجلب البيانات منها في المتصفح.

## أوضاع العرض جنبا إلى جنب

| | Astro (ثابت) | جزيرة Astro | عميل Blazor المعياري |
| --- | --- | --- | --- |
| إنتاج HTML | أثناء البناء | أثناء البناء (بديل مؤقت)، ثم في المتصفح | في المتصفح |
| JavaScript المرسلة | لا شيء | شيفرة تلك الجزيرة | بيئة .NET ووحدات بدء التشغيل |
| أول عرض | فوري | فوري (البديل المؤقت) | بعد بدء بيئة التشغيل |
| مناسب لـ | المحتوى | الأدوات داخل المحتوى | التطبيقات |

## تكاليف يجب مراعاتها

- **بيئة تشغيل واحدة لكل صفحة.** تتشارك كل جزر Blazor في الصفحة بيئة .NET واحدة. تدفع الجزيرة الأولى ثمن
  التنزيل (عدة ميغابايت، تخزن مؤقتا بعد ذلك)، والبقية خفيفة.
- **لا تنقل.** الجزيرة ليست الموجه (Router). لا تستخدم `NavigationManager` للانتقال بين الصفحات من داخل
  جزيرة؛ اعرض روابط عادية.
- **الوحدات.** محمل الوحدات (`ModuleManager`) موجود في مضيف عميل Blazor. ومضيف الجزر لا يعرف إلا المكونات
  التي بني معها. راجع [جزر Blazor](/ar/guides/blazor-islands/#وحدات-وقت-التشغيل).
