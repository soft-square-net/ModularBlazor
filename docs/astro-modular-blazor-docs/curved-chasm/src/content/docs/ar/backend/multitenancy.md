## حدده مرة واحمله في كل مكان

```text
Client ──► Gateway: tenant from host name (acme.example.com) or the JWT tenant claim
              │ forwards X-Tenant header
              ▼
           Pool: validates the header against the token's claim, sets the tenant context
              │
              ├─ gRPC call ──► another pool     tenant id in call metadata
              └─ outbox row ──► broker ──► consumer   tenant id in message headers
```

- **لا تثق بالترويسة وحدها.** تتحقق كل خدمة منها مقابل مطالبة المستأجر في الرمز؛ وترفض الترويسة المخالفة.
- **العمل الخلفي بلا طلب.** يضبط المستهلكون والمهام سياق المستأجر من ترويسة الرسالة أو بيانات المهمة قبل لمس
  بيانات المستأجر.
- **السجلات والتتبعات والمقاييس** موسومة بـ `tenant.id`، فيسهل العثور على مشكلة مستأجر بعينه.

## أين تعيش بيانات المستأجر

مع قاعدة بيانات لكل مستأجر *و*قاعدة بيانات لكل خدمة، يصبح عدد قواعد البيانات = المستأجرين × الخدمات. اختر لكل
مستأجر بدلا من قاعدة واحدة للجميع:

| الخيار | العزل | الكلفة | يستخدم لـ |
| --- | --- | --- | --- |
| قاعدة بيانات مشتركة لكل وحدة، مع عمود `TenantId` ومرشحات استعلام عامة | منطقي | الأقل | الافتراضي |
| قاعدة بيانات مشتركة، ومخطط لكل مستأجر | أقوى | متوسطة | المستأجرون ذوو حجم البيانات الكبير |
| قاعدة بيانات مخصصة لكل مستأجر | الأقوى | الأعلى | المستأجرون المميزون أو الخاضعون للتنظيم |

يسجل مخزن المستأجرين الخيار الذي يستخدمه كل مستأجر وبيانات اتصاله؛ وتحصل الوحدات على اتصالها من خلاله.

## من يملك مخزن المستأجرين

تملك وحدة واحدة مخزن المستأجرين (Multitenancy، أو Identity في السيناريو B). ولا تستعلم الوحدات الأخرى عن جداوله
أبدا:

- تقرأ إعدادات المستأجر عبر بحث مخزن مؤقتا (Redis)، و
- تتفاعل مع أحداث `TenantCreated` و`TenantUpdated` و`TenantDisabled` لتحديث ذاكرتها المؤقتة أو تجهيز مخططها.

## قائمة تحقق

- تتضمن ترويسات الرسائل معرف المستأجر؛ ويفشل المستهلكون بوضوح إن غاب.
- تستخدم مفاتيح أقسام Kafka معرف المستأجر أو معرف التجميعة، لتبقى أحداث المستأجر الواحد مرتبة.
- تحجم مجمعات الاتصال على أساس النسخ × قواعد بيانات المستأجرين × حجم المجمع، أو يتشارك المستأجرون قواعد البيانات.
- تشغل ترحيلات قواعد بيانات المستأجرين مرة لكل إصدار ولكل مستأجر، خارج مسار الطلبات.
