## ما الذي يغطيه هذا الدليل

<CardGrid>
	<Card title="تطبيقان في موقع واحد" icon="puzzle">
		يبني Astro الصفحات العامة (الأخبار والرياضة والثقافة والتوثيق) بصيغة HTML عادية. ويعمل عميل Blazor
		المعياري على مساره الخاص للمستخدمين المسجلين، ويحمل وحداته أثناء التشغيل.
	</Card>
	<Card title="جزر Blazor" icon="rocket">
		ضع مكون Blazor داخل صفحة Astro، ولا تشغله إلا عندما يظهر على الشاشة، تماما مثل `client:visible` في
		Astro.
	</Card>
	<Card title="نظام تصميم واحد" icon="seti:css">
		تعمل متغيرات MudTail ومكوناته وسلوكيات `data-mud` بالطريقة نفسها في صفحة `.astro` وفي قالب Razor.
	</Card>
	<Card title="العربية والإنجليزية" icon="translate">
		كل صفحة هنا متاحة بالعربية أيضا، من اليمين إلى اليسار، تماما مثل MudTail نفسه.
	</Card>
</CardGrid>
