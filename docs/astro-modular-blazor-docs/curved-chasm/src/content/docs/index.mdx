## What this covers

<CardGrid>
	<Card title="Two apps, one site" icon="puzzle">
		Astro builds the public pages (news, sport, culture, docs) as plain HTML. The Modular Blazor client
		runs the signed-in app under its own path and loads its modules at runtime.
	</Card>
	<Card title="Blazor islands" icon="rocket">
		Put a Blazor component inside an Astro page and boot it only when it scrolls into view, like Astro's
		`client:visible`.
	</Card>
	<Card title="One design system" icon="seti:css">
		MudTail's tokens, components and `data-mud` behaviours work the same in an `.astro` page and in a
		Razor layout.
	</Card>
	<Card title="English and Arabic" icon="translate">
		Every page here also exists in Arabic, laid out right-to-left, just like MudTail itself.
	</Card>
</CardGrid>
